- 1. 安全跨越 FFI 边界的类型映射

在跨语言混合项目中，手动手写 `extern "C"` 容易滋生内存泄露和未定义行为。使用 `cxx` 可以在编译阶段对桥接类型进行完备的静态安全检查。

## 1. 安全跨越 FFI 边界的类型映射

```rust
#[cxx::bridge]
mod ffi {
    unsafe extern "C++" {
        include!("engine.h");
        type Engine;
        fn create_engine() -> UniquePtr<Engine>;
        fn run(&self, query: &str) -> i32;
    }
}
```

其跨语言类型安全映射验证由编译期单态化约束保证。
