- 1. 当 -O3 优化悄悄删掉了你的空指针检查

在 C++ 标准中，有符号整数溢出属于 Undefined Behavior (UB)。GCC 会假设其永不溢出，并在死代码消除阶段将边界检查逻辑全部优化掉。

## 1. 当 -O3 优化悄悄删掉了你的空指针检查

```cpp
int check(int x) {
    // 开启 -O3 后，若编译期判定 x + 1 > x 恒成立，整段检查直接消失
    if (x + 1 < x) {
        return -1;
    }
    return x;
}
```
开启 `-fsanitize=undefined` 是排查此类幽灵 Bug 的不二法门。
