- 1. 消除不可预测的 if 分支

现代超标量 CPU 拥有数百级的流水线。分支预测失败的惩罚可高达 15~20 个周期。使用无分支（Branchless）技巧可以将执行时间平滑化。

## 1. 消除不可预测的 if 分支

```cpp
int select_branchless(bool cond, int a, int b) {
    // 编译为 cmov 指令而非跳转指令 jne
    return cond ? a : b;
}
```
