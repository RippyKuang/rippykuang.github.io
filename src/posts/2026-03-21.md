- 1. x86 TSO 与 ARM 弱内存序的碰撞

x86 架构拥有严格的 TSO（Total Store Order），普通的读读、写写不会重排；而在 ARM64 平台上，由于硬件激进的乱序执行，必须严格配对 `std::memory_order_acquire` 与 `std::memory_order_release`。

## 1. x86 TSO 与 ARM 弱内存序的碰撞

```cpp
#include <atomic>

std::atomic<bool> ready{false};
int data = 0;

void producer() {
    data = 42;
    ready.store(true, std::memory_order_release);
}

void consumer() {
    while (!ready.load(std::memory_order_acquire));
    assert(data == 42); // 绝对安全
}
```
其顺序一致性约束满足偏序偏序拓扑。
