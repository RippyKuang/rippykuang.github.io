- 1. 当向量寄存器遇上双重嵌套循环

在矩阵乘法中，合理对内层循环进行向量寄存器广播（Broadcast）与 FMA（Fused Multiply-Add）融合，能够将峰值 FLOPS 提升数倍。

## 1. 当向量寄存器遇上双重嵌套循环

```cpp
#include <immintrin.h>

void matmul_avx2(float* A, float* B, float* C, int N) {
    // 8-wide AVX2 FMA 运算
    __m256 a = _mm256_loadu_ps(A);
    __m256 b = _mm256_loadu_ps(B);
    __m256 c = _mm256_fmadd_ps(a, b, _mm256_setzero_ps());
    _mm256_storeu_ps(C, c);
}
```
