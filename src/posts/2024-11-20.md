- 1. 虚函数表的运行时开销与分支预测

虚函数的多态性通过 vtable 与虚指针实现，但在编译器进行全程序优化（LTO）或类型推导时，如果能确定派生类的唯一类型，编译器将直接将其去虚化为直接函数调用。

## 1. 虚函数表的运行时开销与分支预测

```cpp
struct Base {
    virtual int compute(int x) = 0;
};

struct Derived final : Base {
    int compute(int x) override {
        return x * 2;
    }
};

int benchmark(Derived& obj, int val) {
    // 编译器识别到 final 关键字，直接内联 compute
    return obj.compute(val);
}
```

去虚化后间接跳转指令 `call *%rax` 消除，调用开销由 $\mathcal{O}(L_{\text{branch}})$ 降为 $\mathcal{O}(0)$ 的直接内联。
