- 1. 为什么你的协程会产生意想不到的堆分配？

C++20 无栈协程在挂起时通常需要分配协程帧（Coroutine Frame）。如果编译器无法执行 HALO（Heap Allocation Elision Optimization），高频创建销毁将严重拖垮性能。

## 1. 为什么你的协程会产生意想不到的堆分配？

```cpp
#include <coroutine>

struct Task {
    struct promise_type {
        Task get_return_object() { return {}; }
        std::suspend_never initial_suspend() { return {}; }
        std::suspend_never final_suspend() noexcept { return {}; }
        void return_void() {}
        void unhandled_exception() {}
    };
};
```
